# Module 8: Codes, Standards, and False Alarm Reduction

**You'll be able to:** explain who sets the rules for an alarm install, name the key standards, use false alarm reduction features, and document a job properly.

> These lessons give an overview. Codes are adopted and amended locally, and editions change. Always confirm requirements with your company, the AHJ, and the current adopted edition.

---

## Lesson 8.1: The AHJ

The **Authority Having Jurisdiction (AHJ)** is the office or person who enforces the rules where you're working: often a city or county building department, the fire marshal, or the police department's alarm unit.

The AHJ decides:
- Whether a permit is required for the install
- Which code editions apply
- Whether an inspection is required
- Alarm registration and false alarm fines

When in doubt, call the AHJ before the job.

---

## Lesson 8.2: Licensing, permits, and alarm ordinances

- Many states and cities require **alarm company and/or technician licenses**, sometimes with background checks and continuing education. Know what your state requires before you work.
- Many cities require the **customer to register** the alarm (alarm permit) before police will respond.
- **Alarm ordinances** often set false alarm fees, bell cutoff time limits for exterior sirens, and verification requirements (such as Enhanced Call Verification or video/audio verified response).
- Some jurisdictions use **verified response**: police won't respond to a burglar alarm unless it's verified by video, audio, or a person on site.

## Lesson 8.3: Key standards

| Standard | What it covers |
|---|---|
| **ANSI/SIA CP-01** | Control panel features for false alarm reduction (delays, abort window, swinger shutdown, exit error, and more) |
| **NFPA 70 (National Electrical Code)** | Wiring rules, including power-limited (Class 2) circuits and cable ratings |
| **NFPA 731** | Installation of electronic premises security systems |
| **NFPA 72** | Fire alarm and household fire warning equipment (applies when you install smoke/heat/CO on a panel) |
| **UL 681** | Installation and classification of burglar alarm systems |
| **UL 1023** | Household burglar alarm system units |
| **UL 1610 / UL 1076** | Central station and proprietary burglar alarm units |
| **UL 827** | Central station alarm services |


**UL certificated systems:** some commercial customers (often due to insurance) need a UL certificated burglar alarm system. That means a listed alarm company, listed equipment, installation to UL 681, and a certificate issued for the specific system. This goes beyond v1 but you should know it exists and when to call your supervisor.

## Lesson 8.4: False alarm reduction

Most alarm dispatches are false alarms, and most false alarms are **user error**, followed by equipment and installation problems. Every one costs the customer fines and police time.

**CP-01 panel features** (typical; check the panel and standard for exact defaults):

| Feature | What it does |
|---|---|
| **Exit delay progress / annunciation** | Keypad beeps during exit delay, faster near the end |
| **Exit error** | If an entry door opens and closes during exit delay but isn't closed when the delay ends, the panel goes into entry delay and sends an exit error code instead of an instant alarm |
| **Auto Stay** | If armed Away but nobody leaves through an entry door, the panel automatically arms Stay |
| **Abort window** | Holds the alarm signal briefly so a quick disarm cancels it |
| **Cancel report** | If disarmed after the signal was sent, sends a cancel message |
| **Swinger shutdown** | Limits how many times one zone can trip in an armed period |
| **Cross-zoning** | Requires two zones to trip within a time window before alarming (use with care) |
| **Recent closing** | Reports when an alarm happens shortly after arming |
| **Duress** | Silent signal with a special code |

**Installer practices that prevent false alarms**
- Correct PIR placement and pet settings (Module 3)
- Tight contact alignment and correct gaps
- Interior follower zones on the entry path (Module 7)
- Batteries replaced on schedule
- Thorough customer training (Module 7)

## Lesson 8.5: Documentation

Leave and keep:
- Zone list with device type, location, zone type, wired/wireless, serial numbers
- Wiring diagram or panel drawing for anything non-obvious
- Programming summary or a saved programming file (stored securely)
- Test results and central station confirmation
- Battery install dates
- Permit number and inspection results, if any
- Signed customer acceptance and training acknowledgment

Good documentation saves the next service call, and protects you and your company if something goes wrong.
